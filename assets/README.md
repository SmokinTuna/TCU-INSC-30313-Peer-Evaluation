# Brand assets

Drop optional logo image files here to brand the app header. Both are optional —
if a file is missing, the header falls back to a styled "TCU" wordmark (and a
Horned Frog emoji on the right).

| File                 | Where it appears                | Recommended size |
|----------------------|---------------------------------|------------------|
| `tcu_logo.png`       | Header mark (upper left)        | ~56×56 px, square |
| `horned_frog.png`    | Upper-right corner of the header| ~54 px tall      |

Use official TCU / Neeley logos per your institution's brand guidelines. PNG with
a transparent background looks best. JPG is also supported.
